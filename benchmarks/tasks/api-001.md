# api-001: Add GET /api/projects/:projectId/stats Endpoint

## Category: FEATURE_ADD
## Difficulty: medium
## Expected Intent: FEATURE_ADD

## Prompt
```
Add a new GET /api/projects/:projectId/stats endpoint. It should return: totalTasks, completedTasks, inProgressTasks, overdueTasks (tasks with dueDate < now and status != "done"), and sprintCount. Use Prisma to query the database. Wire it into the project routes file.
```

## Acceptance Criteria
- [ ] GET /api/projects/:projectId/stats returns JSON with all 5 fields
- [ ] Uses Prisma queries (no raw SQL)
- [ ] Route is registered in project-routes.ts
- [ ] TypeScript compiles without errors

## Expected Files Modified
- `src/routes/project-routes.ts`
- `src/controllers/project-controller.ts` or similar
- Optionally: `src/services/project-service.ts`

## Hallucination Signals to Watch
- Creating a StatsService
- Inventing new Prisma models
- Using wrong field names (correct: `status`, `dueDate`, `projectId`)
